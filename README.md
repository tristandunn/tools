# Tools

Random tools generated by Claude Code, likely from iOS.

## Inbox Runner

A 2D side-scroller built with [Phaser 3](https://phaser.io/) (loaded from a
CDN, so there is no build step). Run left to right to the flag at the end of
each level while dodging incoming emails. You can briefly **freeze** every
email on screen to slip past a wall of them.

Controls:

- **Move** — Left/Right arrows or A/D
- **Jump** — Up / W / Space
- **Freeze** — F or Shift (limited charges per level)

The whole thing is static HTML/CSS/JS:

- `index.html` — page + Phaser script tag
- `style.css` — page styling
- `game.js` — the game itself

### Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
# then visit http://localhost:8000
```

### Deploy

Pushing this branch (or `main`) triggers the
`.github/workflows/deploy.yml` workflow, which publishes the site to
GitHub Pages. Enable Pages once under **Settings → Pages → Build and
deployment → Source: GitHub Actions**.
